# 연습장 수정 안내

`index.html`을 Chrome 또는 Edge에서 열어 사용하세요. 이미 열려 있다면 새로고침해 주세요.

- 상단 제목을 ‘연습장 만들기’로 변경했습니다.
- 사용 방법을 듣는 동안 ‘듣기 중지’ 버튼이 나타납니다.
- 그림과 단어 연습장의 위쪽 선이 실제 글자 칸 너비까지만 표시됩니다.
- 인쇄창이 열리지 않으면 인쇄용 HTML 파일을 저장할 수 있습니다. 저장한 파일을 Chrome 또는 Edge에서 열고 ‘인쇄하기 / PDF 저장’을 누르세요.

## 태블릿 필기 확인

글자를 끝까지 쓴 뒤 **‘쓴 글씨 확인’** 버튼을 누르세요. 작성한 칸들을 한꺼번에 확인합니다.

- 파란색 + ‘잘 썼어요’: 정답 모양에 충분히 가깝습니다.
- 빨간색 + ‘다시 써 보세요’: 다른 글자에 더 가깝거나 모양 차이가 큽니다.
- 노란 테두리 + ‘함께 확인해요’: 자동으로 판단하기 어려운 글씨입니다. 선생님과 확인해 주세요.

글자를 고치면 이전 판정 표시가 지워집니다. 고친 뒤 다시 확인해 주세요. 따라 쓰기, 보고 쓰기, 그림만 보고 쓰기 모두 같은 글자 비교 기능을 사용합니다. 보고 쓰기의 보기 글자도 태블릿 화면에 표시됩니다.

## 변경한 판정 방법과 확인 범위

글씨의 위치·크기·펜 굵기를 보정하고 획 중심선과 자음·모음 부분의 모양을 비교합니다. 정답 하나뿐 아니라 비슷한 자음·모음·받침으로 구성된 다른 글자도 비교합니다. 계산은 기기 안에서 실행되며 필기 이미지를 외부 인식 서비스로 보내지 않습니다.

첨부된 화면의 필기 8개(올바른 ‘사·과’ 2개와 다른 모양 6개), 크기를 달리한 글자 및 혼동 글자를 포함한 58개 검증을 통과했습니다. 실제 브라우저에서도 보고 쓰기의 ‘사’와 ‘가’를 구별하고, 그림만 보고 쓰기의 ‘사·과’를 정상 판정하는 것을 확인했습니다. 이는 테스트 사례에 대한 결과이며 모든 학생의 필체에 대한 인식 정확도를 뜻하지는 않습니다. 글자 모양이 비슷하거나 특이한 필체는 ‘함께 확인해요’가 나올 수 있습니다.

## 인쇄 확인 결과

내장 미리보기에서 HTTP 주소로 실행해도 인쇄창이 열리지 않았습니다. 따라서 로컬 파일 형식만의 문제는 아니며, 내장 브라우저의 인쇄 처리 제한과 관련된 것으로 판단됩니다. 앱은 표준 브라우저 인쇄 기능을 호출하고, 응답이 없는 경우 별도 인쇄 파일을 제공합니다. ‘인쇄용 파일 저장’을 눌러 다운로드 폴더에 파일이 생성되는 것까지 확인했습니다. 실제 프린터 출력은 이 환경에서 검증하지 않았습니다.

브라우저의 샌드박스 설정에 따라 print 호출이 제한될 수 있다는 점은 [MDN 인쇄 모달 제한 안내](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/sandbox)에서도 확인할 수 있습니다. 현재 미리보기의 구체적인 내부 설정까지 확인한 것은 아닙니다.

인쇄 파일은 빈 연습장용이며 태블릿 필기와 판정 표시는 포함하지 않습니다. 온라인 그림·글꼴은 다시 열 때 인터넷 연결이 필요할 수 있습니다.
